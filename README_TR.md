# AuthCrate

**Geliştiriciler için kimlik doğrulama sanal ortamı.**

AuthCrate; gerçek OAuth 2.0 / OpenID Connect davranışını yerelde çalıştırır, belirlenmiş test kullanıcıları sunar ve üretim kimlik altyapısına dokunmadan hata senaryolarını canlandırır. Üretim IAM ürünü değildir.

Bu open-source project, [muhammedkoca.com.tr](https://muhammedkoca.com.tr) tarafından geliştirilmektedir. Ana README, Turkish açıklamalarla birlikte developer documentation için yaygın English terminology kullanır.

Başlatmak için `go run . serve` veya `docker compose up --build` kullanın. Keşif belgesi `/.well-known/openid-configuration` yolundadır.
